# Data layout

This repository stores dataset files under `data/`.

## Source dataset

- **IBM Telco Customer Churn**
- Canonical filename used by the notebook: `WA_Fn-UseC_-Telco-Customer-Churn.csv`
- Public source used by bootstrap script:
  - `https://raw.githubusercontent.com/grokify/dataset-telco-customer-churn/main/data/WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Local structure

- `data/raw/telco/WA_Fn-UseC_-Telco-Customer-Churn.csv`
- `data/processed/` for derived artifacts
